# GLOSSARY - pop'n Taisen Puzzle-dama Online (PS2) English patch

One English rendering per Japanese term. Half-width ASCII only (the font's ASCII
set is 1 byte/char; Japanese is 2 bytes, so English almost always fits the slot).
No em/en dashes - use " - ". Keep button glyphs and product names verbatim.

## Core puzzle terms
- たま / 玉 = ball(s)            (the colored puzzle pieces)
- 手玉 = hand ball              (the ball you are dropping)
- 配置玉 = field ball           (balls already placed)
- 攻撃だま = attack balls       (garbage sent to the opponent)
- 連鎖 = chain                  ("3連鎖せよ" -> "Make 3 chains")
- 全消し = clear them all       (board wipe / all-clear)
- 同時に消す = clear at once    ("N個同時に消せ" -> "Clear N at once")
- 倍速 = 2x speed
- 詰めぱずる / 詰めパズル = puzzle mode (set-problem puzzles)
- 問題 = puzzle / problem

## Network / account
- ルーム = room ; エリア = area ; ロビー = lobby
- ユーザー(名) = user(name) ; ID = ID ; パスワード = password
- 会員 = member ; 登録 = register ; 認証 = authentication
- NGワード = banned word
- 対戦 = match / versus
- 接続 = connect ; 切断 = disconnect ; 通信 = connection/comms
- サーバー = server ; ヴァージョン = version

## Buttons / glyphs (keep verbatim)
- ○ × △ □ , L1 L2 R1 R2 , SELECT , START (スタート -> START, スタートで -> Press START)
- ○ボタンで次へ = "○: Next" ; ○で決定 = "○: OK" ; ×で戻る = "×: Back"

## Product names (keep exactly, with their quotes)
- "DNAS"  "PlayStation BB Unit"  "PlayStation 2"  "PlayStation2"

## Tone
- Error table uses a casual tone in JP (...だよ！ / ...してね！). Keep it light but
  clear in English ("That user isn't here!", "Try another name!").
- System/DNAS errors stay plain and factual.
- Honorific さん is dropped in English (name shown bare); the chat fragments
  "<name>さんが、" + "入室しました。" become "<name> " + "has entered."
